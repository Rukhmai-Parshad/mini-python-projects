# Text Editor

A lightweight desktop Text Editor built with Python and Tkinter for creating, editing, and managing text files through a clean and user-friendly graphical interface.

The application provides essential text editing features including creating new files, opening existing files, saving changes, editing text, and displaying word and character counts. Designed with a modular and maintainable approach, the project demonstrates GUI development, event-driven programming, and file handling using Python.

This project focuses on building a practical desktop application while following clean coding practices and software engineering principles.

---

## Features

- Create new text files
- Open existing text files
- Save files
- Save files with a new name (Save As)
- Edit text content
- Cut, Copy, and Paste
- Word count
- Character count
- Dynamic window title updates
- Keyboard shortcut support
- User-friendly graphical interface
- Exception handling

## Installation

Clone the repository:

```bash
git clone https://github.com/Rukhmai-Parshad/python-projects.git
```

Navigate to the project directory:

```bash
cd python-projects/text-editor
```

Run the application:

```bash
python text_editor.py
```

---

## Usage

Launch the application and use the menu options to manage text files.

Typical workflow:

1. Create a new document.
2. Write or edit text.
3. Open an existing text file.
4. Save changes or use **Save As** to create a new file.
5. Use Cut, Copy, and Paste for editing.
6. View the current word and character count.
