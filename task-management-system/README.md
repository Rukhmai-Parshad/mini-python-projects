# Task Management System

A modular Task Management System built with Python to help users efficiently organize and manage daily tasks through a simple command-line interface.

The application supports essential task management operations such as creating, viewing, updating, deleting, searching, and tracking tasks while storing data in JSON format for persistence. The project is designed with a clean and modular architecture, making it easy to understand, maintain, and extend.

This project demonstrates practical Python programming, file-based data management, clean code organization, and software engineering best practices.

---

## Features

- Create new tasks
- View all tasks
- Search tasks
- Update existing tasks
- Delete tasks
- Mark tasks as completed
- Store task data in JSON format
- Persistent data storage
- Input validation
- Exception handling
- Modular project architecture

## Installation

Clone the repository:

```bash
git clone https://github.com/Rukhmai-Parshad/python-projects.git
```

Navigate to the project directory:

```bash
cd python-projects/task-management-system
```

Run the application:

```bash
python task_manager.py
```

---

## Usage

Launch the application and choose the desired operation from the available menu.

Typical workflow:

1. Create a new task.
2. View all tasks.
3. Search for a task.
4. Update task information.
5. Mark a task as completed.
6. Delete completed or unnecessary tasks.
