# Python Projects

A collection of Python applications built to strengthen software engineering fundamentals through clean architecture, modular programming, database integration, file handling, desktop GUI development, and maintainable code.

The projects in this repository focus on solving practical problems while following clean coding practices, proper project organization, and reusable design principles.

---

## Projects

| Project | Description | Technologies |
|----------|-------------|--------------|
| **Contact Management System** | A modular contact management application with CRUD operations, SQLite integration, input validation, logging, and CSV/Excel export support. | Python, SQLite, Pandas |
| **File Management System** | A Python application for performing common file operations including creating, reading, copying, moving, renaming, deleting, and organizing files. | Python |
| **Task Management System** | A task management application for creating, updating, deleting, searching, and organizing tasks using persistent storage. | Python, JSON |
| **Text Editor** | A lightweight desktop text editor built with Tkinter featuring file operations, editing tools, word count, character count, and dynamic window title updates. | Python, Tkinter |

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/Rukhmai-Parshad/python-projects.git
```

### Navigate to the Repository

```bash
cd python-projects
```

### Run a Project

Navigate to the desired project folder and execute the main Python file.

Example:

```bash
cd contact-management-system
python main.py
```

Refer to the individual project documentation for project-specific setup instructions.
