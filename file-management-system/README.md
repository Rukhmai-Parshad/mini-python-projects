# File Management System

A modular File Management System built with Python to perform common file operations through a simple and organized command-line interface.

The application provides an efficient way to manage files by supporting essential operations such as creating, reading, renaming, copying, moving, deleting, and viewing file information. The project is designed with readability and maintainability in mind, making it easy to understand, extend, and reuse.

This project demonstrates practical file handling concepts using Python while following clean coding practices and modular software design.

---

## Features

- Create new files
- Read file contents
- Append text to existing files
- Rename files
- Copy files
- Move files
- Delete files
- View file details
- Check file existence
- Exception handling
- Modular project structure

## Installation

Clone the repository:

```bash
git clone https://github.com/Rukhmai-Parshad/python-projects.git
```

Navigate to the project directory:

```bash
cd python-projects/file-management-system
```

Run the application:

```bash
python file_manager.py
```

---

## Usage

Launch the application and choose the desired file operation from the available menu.

Typical workflow:

1. Create a file.
2. Read file contents.
3. Append new content.
4. Rename a file.
5. Copy or move files.
6. Delete unwanted files.
7. View file details.
